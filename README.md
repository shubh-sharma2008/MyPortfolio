
# MyPortfolio – Shubh Sharma

A responsive portfolio website made as a web development assignment at Lovely Professional University.

## Features
- Profile, courses, skills, projects, education and contact sections
- CSS selectors used: *, element, class, ID, descendant, attribute, :hover, :focus, :first-child, ::before, ::after
- JavaScript: course progress buttons, form validation, character counter, dark mode toggle

## Tech Used
HTML5, CSS3, JavaScript
